# win-clean · 磁盘空间管家

## 0.2.1-preview.3：修复扫描与重复展示

解压试用包后，双击 `Start-WinClean.cmd`。页面自动打开，在页面选择磁盘后开始扫描，清理前先演练并核对路径，最后确认执行。运行只需要 Windows PowerShell 5.1 和现代浏览器，无需 Node、Git 或 Agent。

深入分析遍历所选磁盘，默认不再限时 3 分钟，可随时停止。完整扫描的缓存目录、未完成下载会进入“需要确认”，不自动勾选；个人资料和项目依赖仅供查看。遇到权限不足或取消会明确显示不完整。目录按同层展示，点击下钻，不再把父子目录挤进一张榜单；重叠根目录和嵌套候选去重。容量是逻辑大小，不保证等于物理可释放容量。

开发验证：`powershell -NoProfile -ExecutionPolicy Bypass -File tests/run-all.ps1`。构建 ZIP：`powershell -NoProfile -ExecutionPolicy Bypass -File tools/package.ps1`。运行数据在 `%LOCALAPPDATA%\win-clean`；停止本地服务后也会保留记录。

本版本用于试用验收，尚无签名安装器、自动更新和收费授权；后续见 [商业化路线](docs/commercial-roadmap.md)。以下 Skill 安装方式继续支持。

### 看清磁盘空间，再决定清理什么

win-clean 帮你找出 Windows 上的缓存、临时文件和应用残留，生成可交互的浏览器报告。你在报告中选择要处理的内容，后续执行和结果汇总由 Skill 完成。

## 为什么用它？

- **看得清楚：**按磁盘、体积和风险等级展示发现项，点开就能核对实际路径。
- **由你选择：**先选扫描磁盘，再在页面决定清理内容。
- **分级处理：**可再生缓存与应用缓存采用不同策略，系统级内容只报告。
- **留有记录：**保存扫描、选择和执行结果；可恢复项目提供恢复脚本。

## 快速开始

通过 Skill 安装时需要 Node.js/npm、Git 和兼容客户端；独立 ZIP 版不需要这些依赖。页面建议使用 Edge 或 Chrome。

安装：

```powershell
npx skills add PenglongHuang/win-clean
```

安装时由 `skills` CLI 选择目标 Agent。安装完成后，在支持斜杠命令的客户端输入：

```text
/win-clean
```

也可以直接说：**“C 盘快满了，帮我看看哪些内容占空间。”**

上面的命令默认安装到当前项目。希望在所有项目中使用时，加 `-g`；更新已安装版本：`npx skills update win-clean`，全局安装则加 `-g`。详情见 [skills CLI 文档](https://github.com/vercel-labs/skills/blob/main/docs/commands.md)。

## 使用过程

```text
打开页面 → 选择磁盘 → 扫描 → 选择项目 → 演练核对 → 确认清理 → 查看结果
```

未指定盘符时预选 C 盘，扫描前可调整。默认深入分析，也可选快速检查。扫描只覆盖所选盘符；结果支持分类和路径搜索。同一规则有多个路径时，核对页会逐一列出本次处理路径。

| 等级 | 常见内容 | 处理方式 |
| --- | --- | --- |
| L1 | 可再生缓存 | 永久删除；用户选择 |
| L2 | 临时文件、更新残留 | 永久删除；用户选择 |
| L3 | 应用缓存 | 移入可恢复区；手动选择 |
| L4 | 深度发现 | 移入可恢复区；逐项确认 |
| L5 | 系统级项目 | 仅报告，不执行 |

**提交前请核对路径和处理方式。**L1、L2 删除后无法通过本工具恢复。L3、L4 的可恢复区在本次执行目录中，恢复脚本依赖该目录仍然存在。隔离到同一磁盘通常不会立即释放空间；报告容量也是估算，不等于实际释放量。需管理员权限的项目可能被跳过。

## 数据与隐私

扫描结果、选择、日志、已学习规则和可恢复文件保存在 `%LOCALAPPDATA%\win-clean`，与 Skill 安装目录分开。报告服务只绑定本机回环地址；页面和日志可能含用户名及本机路径，分享前请检查。
