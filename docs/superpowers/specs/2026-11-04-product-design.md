# win-clean 产品化版本

目标：修复扫描浅、无法选盘、页面不自动打开、报告难懂四个已反馈问题。
形态：本机 PowerShell 5.1 服务 + 无外部依赖的浏览器页面，保留 Skill 入口。
流程：启动自动打开 → 选择固定盘和快速/深入模式 → 异步扫描进度/取消 → 结果 → 演练 → 核对 → 执行 → 结果与恢复位置。
视觉：沿用已有暗色界面方向，收敛为深蓝底 #111827、面板 #1e293b、主色 #60a5fa、正文 #f1f5f9、次要 #a8b5c8；Segoe UI / 微软雅黑。以磁盘容量条和按大小排序的清单为中心，取消重复地图与列表。
扫描：规则扫描保持兼容；新增显式栈遍历、不跟随重解析点、时间预算、取消标记、无法访问计数。记录大目录与大文件，仅报告，不能直接清理。按盘限定扫描，非法盘符拒绝。
安全：回环绑定、随机会话令牌、同源 POST、请求大小与超时限制、固定资产白名单；执行必须绑定当前扫描哈希与演练选择；执行中不能开始另一轮扫描；不自动提权。实际删除只允许 execute.ps1。
统计：删除预计释放、隔离体积、仅查看占用分别展示。占用是逻辑字节，不能等同物理可释放容量；扫描覆盖与预算中止明确展示。
范围：本轮实现可试用产品基础，不宣称已具备代码签名、自动升级、收费授权或完成真实用户验收。保留旧报告和 CLI 兼容。
