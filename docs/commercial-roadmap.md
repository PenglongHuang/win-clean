# 商业化交付路线

当前交付是 0.2.1-preview.3 本地试用版本，面向普通 Windows 用户；运行不要求安装 Node 或 Git。

先验证用户能独立完成选盘、扫描、演练、确认、执行，记录扫描耗时、空间大户发现情况、清理成功和误判反馈。反馈默认留在本机，分享前由用户检查路径与隐私。

收费发行前仍需完成：

1. Windows 10/11 普通与管理员账户、长路径、多卷、运行中文件、断电后的恢复验证。当前自动化不替代多环境验收。
2. 安装器、代码签名、明确发行许可、升级与回滚。当前仅有 ZIP 试用包。
3. 清理规则逐项审核：影响、适用版本、命中证据、误判处理。空间大户不直接转为可删除规则。
4. 大磁盘性能基准、流式统计与断点继续。当前已取消默认时间截断、优化为按目录汇总；仍需更多机器基准。权限不足、链接跳过和取消均影响覆盖，逻辑大小不等于物理占用。
5. 经试用确定付费权益、价格、授权、退款和支持渠道。本轮不接收费服务、不设虚构价格。

先以任务完成率和误判反馈决定下一轮，不将预览版标为商业正式版。
